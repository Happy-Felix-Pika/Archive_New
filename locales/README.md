# Переклади інтерфейсу

```
locales/uk.json                          ядро: ключі (nav.overview…) українською
locales/en.json                          ядро: англійська
apps/installed/<id>/locales/en.json      кожен застосунок — свої написи окремо
```

**Українська — базова мова.** Написи пишуться прямо в коді українською, тож
окремий файл з українськими фразами не потрібен (uk.json — лише для старих
ключів на кшталт `nav.overview`).

`en.json` — плоский словник «українська фраза з коду → переклад»:

```json
"Видалити теку «{0}»": "Delete folder «{0}»",
"Завантажено: {0} з {1}": "Uploaded: {0} of {1}"
```

`{0}`, `{1}`… — змінні частини (імена, числа). Емодзі й розділові знаки по
краях у ключ не входять.

Сервер склеює ядро й усі застосунки в `/i18n.js`, а `static/i18n.js` на
сторінці сам підставляє переклад: текст, підказки, тости, діалоги,
повідомлення сервера. Мова перемикається кнопками UK / EN унизу меню.

**Додав новий текст?** Увімкни EN, відкрий потрібну сторінку, у консолі
браузера виконай `i18nMissing()` — отримаєш шматок JSON з неперекладеним;
впиши переклади в en.json ядра або того застосунку, чий це текст.

**Нова мова** (напр. польська): скопіюй en.json → pl.json (в ядрі й
застосунках) і переклади значення; кнопку мови додати в dashboard.html.
